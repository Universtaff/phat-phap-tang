# Phật Pháp Tăng · Theravāda

**▶ Xem web / Visit:** https://universtaff.github.io/phat-phap-tang/ · **YouTube:** https://www.youtube.com/@phatphaptanggz

## Tiếng Việt

Trang web của kênh Phật Pháp Tăng: kể chuyện Đức Phật, kệ Pháp Cú và giáo lý Theravāda, bám theo Tam tạng Pāli. Mỗi tập có một trang riêng gồm video, toàn văn lời kể và nguồn kinh để bạn tự tra lại.

- Trang tĩnh, dựng bằng `lam-web.mjs` từ `du-lieu.json`.
- GitHub Actions dựng lại mỗi ngày, tập nào vừa công khai trên YouTube thì tự có trang.

## English

The website of the Phật Pháp Tăng channel: stories of the Buddha, Dhammapada verses and Theravāda teachings, following the Pāli Canon, in Vietnamese. Each episode has its own page with the video, the full narration and the scripture sources so you can check them yourself.

- Static site built by `lam-web.mjs` from `du-lieu.json`.
- GitHub Actions rebuilds it daily; an episode gets its page as soon as it goes public on YouTube.

## Chạy / Build

```
YT_API_KEY=<khoá YouTube Data API> node lam-web.mjs   # → _site/
```
